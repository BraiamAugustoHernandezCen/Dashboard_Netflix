# Dashboard_Netflix

La economía del entretenimiento: Netflix y tendencias globales

Equipo: Braiam Hernández (proyecto individual)

Integrantes
Braiam Augusto Hernández Cen
Descripción del proyecto

Dashboard dinámico desarrollado con React que analiza el catálogo de Netflix (dataset Netflix Movies and TV Shows de Kaggle) para visualizar tendencias de producción, géneros más populares y distribución geográfica del contenido. Es un dashboard de tipo estratégico dirigido a personas que toman decisiones de contenido.

Indicadores y gráficos
Número de títulos por país (mapa de calor)
Evolución de lanzamientos por año (gráfico temporal)
Top 5 géneros y top 5 directores más productivos (nube de palabras de géneros)
Películas vs. series (gráfico circular)
Tecnologías
Frontend: React
Base de datos: PostgreSQL
Despliegue: GitHub Pages / Vercel / Netlify
